📌 About This Workshop
Welcome to Workshop-genAI 🎉 This repository contains hands-on implementations and experiments from a Generative AI Workshop, where we explore: 🤖 Large Language Models (LLMs) ⚡ FastAPI backend integration 🔥 Groq / OpenAI APIs 🧠 Prompt Engineering 🛠 Building AI-powered applications
